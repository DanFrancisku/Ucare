# Ucare – Demo

Ucare is care software for supported living and care homes (SEND / autism care).

**This is a demo only. All names and records are made up.**

## What the demo shows
- 4 demo users: Support Worker, Manager, Director, Family
- Each person has their own flat, inside a unit (Alpha, Beta, Gamma, Theta)
- 1:1 and 2:1 support per shift
- Shifts: Day 09:15–15:15, Evening 15:00–22:00, Night 21:45–09:30
- Day centre days, and "where is the person now"
- Care notes, incidents (ABC), handovers per flat, rota
- Manager review of incidents, director overview

## How to open
Open `index.html` in a browser. Data is saved only in your own browser.
